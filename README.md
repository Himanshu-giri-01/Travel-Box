# Travel Box Holidays — Premium Luxury Travel Website

Official bespoke website for **Travel Box Holidays**, a premier travel agency located at Exhibition Road, Patna, Bihar.

Designed with an **editorial luxury aesthetic**, featuring rich typography, authentic destination photography, responsive WhatsApp journey planner, and transparent Google rating social proof (4.8 ★ from 255+ reviews).

---

## 🌟 Key Highlights

- **Luxury Editorial Design**: Warm ivory backgrounds, charcoal/obsidian surfaces, champagne gold accents, and bespoke typography pairing (`Cinzel` & `Cormorant Garamond` with `Plus Jakarta Sans`).
- **Zero Generic AI Clichés**: Clean visual hierarchy, authentic travel imagery, no fake badges or neon gradients.
- **WhatsApp Concierge & Journey Planner**: Interactive enquiry form that compiles structured travel inquiries and opens WhatsApp directly to `+91 96544 22590` across desktop and mobile.
- **Grouped Service Suite**:
  - *Holidays & Vacations* (Family, Honeymoon, Adventure)
  - *Flight, Visa & Logistics* (Air Tickets, Luxury Hotels, Visa & Passport Assistance, Forex & Travel Insurance)
  - *Business & Special Journeys* (Corporate Travel, Destination Weddings, Customized FIT Packages)
- **Popular Destinations**: Maldives, Dubai, Bali, Europe, Kashmir, Andaman, and more.
- **Google Social Proof**: 4.8 ★ rating with verified customer review themes.
- **Patna HQ Office**: Detailed address on Exhibition Road with embedded Google Maps navigation and one-tap calling.
- **SEO & Schema.org**: Fully integrated `LocalBusiness` JSON-LD structured data and Open Graph meta tags.

## 🚀 Getting Started

### Local Preview
Simply open `index.html` in any modern web browser or run a lightweight local server:

```bash
# Using Python
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
